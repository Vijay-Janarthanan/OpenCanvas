Quickstart Integration

Add OpenCanvas to your project in just a few lines of code.

📦 1. Add Gradle Dependency

Add JitPack to your repositories and include opencanvas-core:

// settings.gradle.kts or build.gradle.kts
dependencyResolutionManagement {
    repositories {
        mavenCentral()
        maven { url = uri("https://jitpack.io") }
    }
}

dependencies {
    // Core resolution engine & stream extractor
    implementation("com.github.Vijay-Janarthanan:OpenCanvas:1.0.0")
}
Example Usage 
import com.opencanvas.core.OpenCanvas
import com.opencanvas.core.models.OpenCanvasMode
import com.opencanvas.core.models.OpenCanvasResolution

// 1. Resolve an 8-12s chorus hook loop in 480p mobile standard
val loopTrack = OpenCanvas.resolve(
    title = "Blinding Lights",
    artist = "The Weeknd",
    mode = OpenCanvasMode.LOOP_CANVAS,
    resolution = OpenCanvasResolution.STANDARD_480P
)

// 2. Playable MP4 stream URL directly for ExoPlayer / Media3:
val videoUrl = loopTrack?.playableStreamUrl
exoPlayer.setMediaItem(MediaItem.fromUri(videoUrl))
exoPlayer.prepare()
import com.opencanvas.core.OpenCanvas
import com.opencanvas.core.models.OpenCanvasMode
import com.opencanvas.core.models.OpenCanvasResolution

// Desktop HD mode (720p or 1080p Full HD)
val desktopTrack = OpenCanvas.resolve(
    title = "Starboy",
    artist = "The Weeknd",
    mode = OpenCanvasMode.FULL_SYNCED_VIDEO,
    resolution = OpenCanvasResolution.HD_720P
)

// Render in Compose Multiplatform window with Skiko or JavaFX:
DesktopVideoSurface(streamUrl = desktopTrack?.playableStreamUrl)
import { OpenCanvas, OpenCanvasMode } from '@opencanvas/core';

const track = await OpenCanvas.resolve({
  title: "Blinding Lights",
  artist: "The Weeknd",
  mode: OpenCanvasMode.LOOP_CANVAS,
  resolution: "480p"
});

// Render in HTML5 or React Native Video:
<video src={track.playableStreamUrl} autoPlay loop muted playsInline style={{ objectFit: 'cover' }} />

Configurable Resolutions & Custom Dimensions

Control video dimensions and bandwidth consumption per device profile.

360p Low
640 × 360

~5.9 MB buffer. Zero lag on cellular data or older devices.

480p Standard
854 × 480

~9.7 MB. Recommended mobile standard matching Spotify Canvas.

720p HD
1280 × 720

~18.6 MB. Crystal crisp for tablets, laptops, and desktop.

1080p Full HD
1920 × 1080

Maximum visual fidelity for 4K and large monitors.

Custom Dimensions via Code:

// Custom height and width:
val customRes = OpenCanvasResolution.fromDimensions(height = 720, width = 1280)

// Dynamic string parsing from settings:
val parsedRes = OpenCanvasResolution.fromLabel("480p")

Planned Pipeline Architecture

From raw track title to hardware-accelerated 60 FPS vertical playback.

1

Official Video Matcher (InnerTube API)

Discerns official music videos from fan uploads, audio-only tracks, and reaction videos using exact metadata and length bounds.

2

Climax Heatmap Parser

Parses YouTube's "Most Replayed" markers directly to locate the 8–12s chorus hook with 0 ms audio DSP delay.

3

Dynamic Stream Resolution Selector

Selects matching video streams for 360p, 480p, 720p, or 1080p profiles via optimized format descriptors.

4

Saliency Kinematics & 1-Euro Filter

Applies an adaptive low-pass filter to eliminate panning jitter, snapping to camera scene cuts instantly with 0 ms whip-panning.

5

Zero-Reencode Hardware Viewport Crop

Streams directly to GPU matrix layers (Compose graphicsLayer / Skiko) at 60 FPS with zero CPU spikes.
